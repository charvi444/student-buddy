# 📚 Student Buddy

Student Buddy is a Chrome Extension designed to help students stay organized by managing tasks, taking notes, and accessing frequently used study resources from a single, easy-to-use interface.

## ✨ Features

- ✅ Create and manage daily to-do lists
- 📝 Take and save quick notes
- 🔗 Quick-access shortcuts to useful study resources
- 💾 Persistent data storage using Chrome Storage API
- 💡 Display motivational quotes fetched from a public API
- ⚡ Real-time updates within the extension popup

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Chrome Extensions API
- Chrome Storage API
- Public Quotes API

## 🚀 Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/charvi444/student-buddy.git
   ```
2. Open Google Chrome and go to:

   ```
   chrome://extensions
   ```
3. Enable **Developer Mode**.
4. Click **Load unpacked**.
5. Select the project folder.
6. The Student Buddy extension is now ready to use.

## 📖 Usage

- Add and manage your daily tasks.
- Save important notes.
- Access study resources quickly through shortcuts.
- Stay motivated with inspirational quotes displayed in the extension.
